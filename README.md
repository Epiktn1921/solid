# Принципы SOLID на примере сайта-портфолио

Контрольная точка 3 по дисциплине «Архитектура программного обеспечения».

Примеры написаны на **TypeScript** и построены на частях моего сайта-портфолио «Таня Эпик»:
работы в галерее, ссылки на контакты, просмотрщик работ, слайды и рилсы, кнопка «Скопировать почту».
В каждом файле сначала показан код, который **нарушает** принцип (❌), затем — исправленный вариант (✅).
Подробные пояснения — в комментариях в коде.

| Принцип | Файл | Пример из портфолио |
|---|---|---|
| **S** — Single Responsibility (единственная ответственность) | [`src/1-srp.ts`](src/1-srp.ts) | Работа: данные, отрисовка карточки и хранение разнесены по разным классам |
| **O** — Open/Closed (открытость/закрытость) | [`src/2-ocp.ts`](src/2-ocp.ts) | Контакты: новая соцсеть добавляется новым классом, без правки старого кода |
| **L** — Liskov Substitution (подстановка Лисков) | [`src/3-lsp.ts`](src/3-lsp.ts) | Просмотрщик: рилс подставляется вместо постера и ничего не ломает |
| **I** — Interface Segregation (разделение интерфейсов) | [`src/4-isp.ts`](src/4-isp.ts) | Слайды, постеры, рилсы реализуют только нужные им интерфейсы |
| **D** — Dependency Inversion (инверсия зависимостей) | [`src/5-dip.ts`](src/5-dip.ts) | Кнопка копирования почты зависит от абстракций, поэтому её можно проверить без браузера |

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm start
```

`npm start` компилирует TypeScript в папку `dist/` и по очереди запускает все пять примеров.
